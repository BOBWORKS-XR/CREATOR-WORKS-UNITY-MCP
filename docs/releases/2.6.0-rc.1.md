# Creator Works MCP 2.6.0-rc.1

Unpublished release candidate. The installed local 2.5.1 test build is separate.

## Changes

- Focused documentation lookup with corrections and continuations; full references remain available.
- Bounded compact replies and optional tool profiles. Full retains 52 tools; core exposes 24.
- Identity-only component inventories, hidden/nested property lookup, renderer enabled state, and explicit missing-property reports.
- Compile/domain-reload waits require a fresh settled Editor. Pending menu/query timeouts carry project-bound polling arguments and warn against resubmission.
- Optional restriction on unfiltered Unity test runs; project-scoped policy survives domain reload and setup preserves existing fields.
- Multi-platform packaging workflow and cross-platform standalone setup assets. Checksum consolidation rejects missing platforms, incomplete uploads, invalid digests, and unsafe filenames.

installer is unsigned. Linux/macOS workflow CI on the contributor branches is
not proof that the combined candidate has been installed or run on those systems.
No end-to-end token-percentage or provider-quota saving is established.

Before stable release: install/upgrade the candidate, reconnect clients, update
the chosen project bridges, and repeat normal scene/graph tasks. Confirm errors,
project identity, pending-command recovery, and Editor responsiveness. Hosted

project just to run this release check.
