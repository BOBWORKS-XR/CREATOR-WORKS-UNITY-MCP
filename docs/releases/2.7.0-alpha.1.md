# Creator Works MCP 2.7.0-alpha.1

Windows test release for the coordinated Creator Hub preview. No stable/main
promotion. The existing Unity tools, SDK profiles, Visual Scripting knowledge,
and token-aware reference/response limits remain available.

## New in This Preview

- Compact shared Creator interface and accessible app switcher.
- Normal MCP controls inside a compatible Creator Hub, after an explicit native
  approval prompt. Uses the installed app's resources and existing settings;
  it is not a second, disconnected project list.
- Standalone MCP remains usable without Hub. Installing Hub does not rewrite
  shortcuts, import projects automatically, or stop healthy MCP clients.
- Guarded Windows NSIS upgrade path, including paths containing spaces. Active
  launcher/runtime checks refuse unsafe updates instead of force-closing them.
- Signed release metadata for Hub to verify downloads and the actual installed
  launcher. This is separate from Windows publisher signing; the EXE is unsigned.
- Bundled original dependency notices and inventories in `licenses`: Rust,
  locked production Node packages, Lucide/Feather, and source/brand notices.
  The private Node runtime also keeps its own full license beside the executable.

## Test It

1. Install the coordinated Creator Hub preview once and enable Include prereleases.
2. Select Creator Works MCP and choose Install app or Update app.
3. Save work and close active MCP clients if requested. Do not remove settings.
4. Choose Open hosted development preview, then approve Enable MCP controls.
5. Verify your project list and selected project. Update project bridges explicitly
   only where needed, reopen Unity, reconnect the AI client, and check bridge status.

The direct Windows installer remains available for standalone use. Older MSI,
unknown, duplicated, and custom-location installations may need a separate
reviewed migration; the preview does not silently overwrite or remove them.

## Acceptance and Limits

The Windows acceptance artifact tests the real 2.6.0 to preview NSIS update,
blocked active-runtime updates, cooperative exit, exact installed payload/license
hashes, preserved settings/unmanaged-file sentinels, and busy-uninstall refusal.
The release uses those tested installer bytes, not a tag-triggered rebuild.
CI reports are linked from the GitHub release after acceptance.

Hub separately tests the final signed public app pair through its actual native
window. Source and browser tests alone do not establish that integration.
An opaque settings sentinel is not proof of every historical configuration
migration. Full installer rollback, automatic shortcut adoption, idle handoff
of an already-open app, and native macOS/Linux Hub hosting are not promised.

There is no new measured token-saving percentage in this preview. Existing
token-efficiency behavior remains; no end-to-end account/quota savings are claimed.
Unity compilation, SDK behavior, manual scene preservation, and headset/multiplayer
results still need testing in the user's actual project.
