# Creator Works MCP 2.6.0

The first token-efficiency release is now on the stable line, with corrections
from architectural scene work and Forest bridge feedback. This is a new build,
not a relabelled 2.6.0-rc.1 installer.

## Benefits

- New setups use 25 core tools instead of all 53; existing Full choices remain Full.
- Focused reference lookup carries the manual corrections, without repeatedly loading whole catalogs. Specialist profiles and full references remain available.
- Bounded scene/component/console/compiler replies preserve errors, freshness and omissions.
- Deep active-scene hierarchies are no longer silently cut off after depth 10. Completeness and response-limit metadata are visible before data.
- Create/modify replies include observed world/local transforms rather than relying only on the requested values. Legacy request summaries are labelled; measurements describe the immediate post-apply state, not later physics or hosted behavior.
- Compile waits survive reload. Long commands retain a dispatch record even while Unity blocks the pipe/heartbeat. Poll the original ID, do not duplicate a build. The newest 200 status records are retained; a dispatch receipt is not proof of build completion or continued liveness.
- Local feedback and optional usage check-ins help collect real-world evidence without telemetry or account access.
- The launcher can check for newer stable releases. Automatic metadata checks are optional; installation and bridge updates remain manual.
- Updated the existing Hono pin to [4.13.5](https://github.com/honojs/hono/releases/tag/v4.13.5), which contains upstream security fixes. No additional runtime dependency was introduced.

## Optional Feedback

Enable **Local feedback for selected project** in the launcher, or explicitly
authorize `project_feedback` configuration. The file is
`.bantworks-mcp/feedback/MCP_FEEDBACK.md`, outside Unity's compiled assets.
Notes include MCP/bridge versions when the bridge version is available, plus
the bounded facts supplied by the caller. They do not include project contents,
screenshots, account credentials, or private logs automatically.

Usage check-ins are a separate opt-in: the AI calls `task_complete` at a genuine
task boundary, and the tool returns a suggested optional question only after at
least five unique tasks and 24 hours. Skip freely. Recording usage requires
explicit consent for that report. The file stays local until its owner chooses
to share it; inspect and redact it first. This is voluntary feedback, not billing
measurement or a token-saving guarantee.

## Upgrade

1. Back up work and save/close projects whose bridge you will update.
2. Install the matching release package. Close MCP clients if the private runtime is locked; Setup never force-closes them.
3. Open the launcher and use **Update Bridges** deliberately for your projects.
4. Reopen Unity, allow compilation, and reconnect the MCP client.
5. Check the selected project, bridge version `2.6.0`, and intended capability profile.

Windows x64 EXE, Linux x86_64 AppImage/DEB/RPM, macOS Apple Silicon DMG, and the
standalone Node.js ZIP are published with SHA-256 checksums. Windows remains
unsigned and macOS is not notarized; checksums prove integrity, not publisher
identity. Existing app identity/settings migration are preserved.

## Evidence and Limits

Local automated checks cover the server, launcher settings, consent/disabled
states, task deduplication and cooldown, update metadata validation, and retained
command correlation: 195 Node tests and 23 Rust tests passed, with a clean npm
audit and isolated bundled-server smoke. The frontend passed headless Edge
checks at 900 and 560 pixels using mocked native IPC/GitHub responses; this is
not a clean installed-app upgrade test. Disposable Unity 2022.3.39f1 and 6000.3.21f1 fixtures exercise
32-level hierarchy export, scaled-parent transform receipts, parent following,
and a blocking menu with readable dispatch status. These are Editor fixtures,
not hosted Forest or headset acceptance of the release.

Measured tool schemas: core 23,172 bytes; Full 48,613 bytes, about 52% less for
core. Results do not establish whole-task token, cost, quota or latency savings.
New optional feedback adds one tool; Full functionality remains available.

General hierarchy pagination, batch bounds, rename/cutaway tooling, safe background
installer downloads, render-pipeline conversion, one-click SDK installation,
manual-edit conflict control and the player emulator are not part of this release.
Shader Graph mutation remains experimental. The reported child-following failure
was not reproduced in the fixture; no speculative reparenting change was made.

Thanks to FireRat for the included cross-platform packaging and test-policy
contributions, and to people supplying concrete project feedback. No private
feedback journal or user project files are included in the release.
