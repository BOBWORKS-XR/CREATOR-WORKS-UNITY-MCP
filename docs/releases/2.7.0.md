# Creator Works MCP 2.7.0

Windows update for the coordinated Creator Hub release. MCP remains a standalone
app as well as a compatible Hub tool, using the same saved projects and settings.
Linux/macOS packages stay on the separate 2.6.0 release track.

## New and Improved

- **Creator Plugins:** browse shared community contributions, previews, authors,
  requirements and usage notes. Supported Unity packages can be sent to a
  selected project for review. AI skills, MCP tools and instructions-only items
  are not imported into Unity as executable assets.
- **Unity menu:** browse from Creator Plugins > Browse inside Unity. Imports
  still use Unity's file-selection dialog. Code warnings stay visible.
- **Clear import outcomes:** queued, under review, cancelled, failed and imported
  are distinct states. A restart does not invent a successful outcome or retry.
- **Retry without losing history:** an explicit retry creates a new request.
  Completed requests move to history; their final receipts remain unchanged.
  Unity and desktop apps share a nonblocking queue lock and a 100-pending limit.
  Missing or malformed receipts never count as completed imports.
- **Known-helper upgrades:** the exact supported older Unity menu can be updated
  after closing its project. The complete old folder is backed up, Unity metadata
  is retained, and custom or unexpected files block replacement.
- **Safer app upgrades:** installer checks refuse busy installed components.
  Settings and unrelated content are retained. No unrelated Node or AI processes
  are force-closed.
- **Shared presentation:** compact navigation and the Creator Plugins icon match
  the suite, with accessible navigation and original dependency notices included.

## Upgrade

1. Save work. In Creator Hub, choose Update app for MCP, or run the direct Windows
   installer from this release.
2. Close active MCP clients or the app when requested, then retry. Do not uninstall
   or delete application data as a normal upgrade step.
3. Reopen MCP and check your saved project list. Update project bridges only where
   needed. Close the selected Unity project before updating its Plugins menu.
4. Reopen Unity and reconnect the AI client. Confirm bridge status before editing.

Package imports remain optional and require your review. Checksums verify bytes,
not code safety. C# can run during Unity import; read the contributor's source and
requirements before proceeding. Imports do not automatically save your scenes.

## Checks and Limits

Source validation covers Unity 2022.3.39f1 and 6000.3.21f1: each passed 193 queue
and helper checks, 10 restart/callback checks, and 101 offline protocol/lock checks.
The lock checks include actual cross-process Windows Rust/C# exclusion and release.
They do not establish native macOS/Linux interoperability or actual package-import
acceptance for every plugin.

The Windows installer acceptance matrix uses one exact candidate against 2.6.0,
2.7.0-alpha.1 and the pinned accepted alpha.2 CI artifact. It checks busy-runtime
refusal, cooperative exit, exact installed payloads, settings and unmanaged-file
preservation. Publication is gated on that matrix and coordinated Hub checks;
see the release's verification attachments for the final artifacts and results.
Alpha.2 is a CI baseline, not a claimed public release.

The installer remains unsigned by a Windows publisher. Signed Hub metadata and
SHA-256 checksums are separate from Authenticode signing. Unknown or duplicate
installations still need explicit selection rather than automatic removal.

Existing token-efficient profiles, focused documentation, and bounded scene
responses remain. This release claims no new end-to-end token or quota savings.
Unity compile/build checks do not prove headset, hosted loading, interaction or
multiplayer behavior. Verify those in your actual project.
