Creator Works MCP help

MCP connects a supported AI client to Unity tools. It is not the AI model.

Which Creator app am I using?

Creator Works MCP connects a supported AI client to Unity tools. Project Setup creates and validates Creator SDK projects. Creator Hub manages apps and projects. Creator Plugins is the community catalogue, also available in Hub and the Unity Editor window.

Why doesn't my AI see MCP?

Check MCP's connection/setup status, confirm your AI client supports MCP, and restart or reconnect that client after configuration changes. Claude CLI is supported; Claude Desktop is not currently supported. The AI model and its billing are supplied by your client/provider.

Why is AI using so many tokens?

Token use depends on the client, model, prompt, context and settings. Check provider usage/billing, avoid sending unnecessary project context, disable fast or high-cost modes where available, and try a cheaper or older model for routine MCP tasks. Complex models are not usually necessary for straightforward tool actions. MCP cannot predict or cap charges.

What do plugin types mean?

Visual Scripting is a graph; a prefab is a reusable object hierarchy; scripts and editor tools contain code; a scene is a larger project composition. Packages may include more than one type and have dependencies. Follow the listing's destination/version instructions, back up your project, then use the catalogue's supported import flow. MCP itself does not install community packages.

What are Project Setup and Hub for?

Use Project Setup for a guided, pinned Creator SDK project recipe and existing-project checks. Use Hub to manage installed Creator apps, find your projects and browse community Plugins. Unity sign-in/licensing and your AI provider account remain separate.

How do I report a problem?

Include this app's version, AI client name/version, the exact MCP status or error, and relevant local logs. Remove API keys, tokens, private project paths and other sensitive data before sharing. Keep project backups before AI-driven changes.
